# 仅执行命令的会话保留在列表中

[English](guide.md) | 中文

## 变更

此前，会话列表的空白标记仅在 `turn/start` 时清除，因此日志中只提交过斜杠命令（`command/run`）的会话被视为空草稿：在列表中隐藏，并可被新建会话复用。自本版本起，已提交的 `command/run` 也会清除空白状态，等待确认的命令在离开当前会话后仍有可返回的入口。`sessionListMetadata` 投影升至状态版本 2；已历经轮次的 version-1 持久化缓存行继续提供服务，仍为空白的 version-1 行与缺失行由有界且不激活 Agent 的日志重算回答（每个冷行至多 `SESSION_COLD_RECOMPUTE_EVENT_LIMIT` 个事件），无法判定的行保持会话可见而不是隐藏。

升级后，拥有只执行过命令的会话的用户会在列表中看到这些会话；真正空白的草稿保持隐藏。

## 迁移

1. 无需任何操作。升级后的首次 `session.list` 对无法判定的冷行执行一次重算并刷新其持久化投影缓存；超大或不可读的日志在其会话被打开前保持可见。
2. 打开会话列表即可确认升级正常：仅执行命令的会话按其最近活动显示，空草稿不出现，且没有会话重复。
