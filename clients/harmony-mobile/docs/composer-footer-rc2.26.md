# rc2.26 会话底部输入区候选

[rc2.25 原机观察](mvp-rc225-a6-a7-20261031.md)确认长历史会将输入框、发送和停止按钮推离可见区域。当前原生页面使用填满键盘调整后视口的 Column；历史 Scroll 只占剩余高度，会话输入区与任务按钮作为同级底部内容保留自身高度。按钮继续自动换行，没有缩小字号或点击区域；键盘策略仍为 `RESIZE`，没有自动弹出键盘。

本轮产品改动仅为 `Index.ets` 的布局。会话选择、逐会话草稿、按钮回调及授权检查保持一致；原配对、历史、原生存储、网络协议和中继配置没有变化。与 rc2.25 封存输入比较，149 项共享源码、其余 72 项原生输入、三份生成 bundle 和共享 guest SDK 一致。主工程生成文件与旧候选保留。底部布局的编译和结构检查不能证明真机像素布局、输入法或自动输入失败已经修复。

## 离线证据

[最终核验](../evidence/composer-footer-rc2.26-20261031.json)记录去重后的 139 项定向检查：117 项消息／页面／布局检查、17 项新候选 Core 的恢复／启动检查，以及 5 项本地日志检查。官方 ETS 解析检查拒绝输入区重回历史、历史占满视口、底部错误分配权重、键盘不调整视口及不换行按钮组；按钮回调与改动前快照一致。[局部正确性 lint 与文档检查](../evidence/composer-footer-final-review-20261031.json)通过；没有运行仓库总回归或模型测试。

原恢复检查入口先因缺少加载器参数、随后因旧 Core 报告的 `upstream.ts` 指纹过期而拒绝。这两次失败保留；通过检查使用独立候选中重新生成的 ProductCore／PairedCore 和现有 17 项测试，没有改写主工程生成文件或旧构建报告。

[官方 API26 构建](../evidence/native-build/2026-10-31T13-04-54-806Z.json)退出码为 0，原生输入编译期间不变，JS 导入检查通过。第一次沙箱构建被官方 Hvigor 链接权限阻止，同一命令经宿主重试成功；既有异常处理及设备能力警告保留。HAP 大小 5,730,606 字节，SHA-256 为 `cddf5da9d12ec2872728889a65914ea13a9d2b03133b00701f8826536714d2a9`。

[手机候选归档](../handoff/phone-rc2.26-20261031.zip)包含完整未签名 HAP、原生构建输入、内容寻址的共享源码快照及验证记录；[归档清单](../evidence/phone-candidate-rc2.26-20261031.json)记录摘要，[独立载荷核验](../evidence/phone-rc226-artifact-smoke-20261031.json)检查版本、权限、CRC、文件集合和逐字节载荷。归档保留未签名字节，其后已完成[原签名原位安装与单窗口实测](mvp-rc226-window-20261031.md)，手机现为 rc2.26，桌面继续使用 rc2.23，原配对、UID 和数据保留。
