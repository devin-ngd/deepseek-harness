# 已配对设备自动连接

手机后续已更新至 [rc2.31 会话误报修复](session-catalog-ready-rc2.31.md)，桌面和中继仍为 rc2.30；下文保留自动连接的设置和首次部署记录。

## 日常使用

电脑 DSH 开着、固定中继运行时，打开手机 DSH 即使用原配对自动连接并加载会话列表。两端可以先后打开，不需要交换路由 JSON、逐次确认或同时点击。网络断开后每 5 秒尝试重连；手动“断开连接”会停止本次自动重连，再点连接或冷启动应用即可恢复。重连不会重发消息或恢复提交任务。

未配对设备仍需首次配对，已撤销的设备不能自动连接。原身份、绑定、会话及已结束的临时路由历史保留。手机沿用用户的深色界面改版，仅隐藏日常无需使用的路由准备区，并将关闭窗口按钮改为断开连接。

## 一次更新范围

- 手机：原签名材料原位更新到 rc2.30，候选配置启用 `deviceAutoConnect: true`、`deviceReconnectMs: 5000`。
- 桌面：更新 Harmony 插件到 rc2.30，现有 device 组件使用 `connectionMode: paired`、`reconnectMs: 5000`，正常重开 DSH 后自动等待原手机。`connectionMode: window` 保留显式临时窗口模式。
- 固定中继：更新程序并启用 `pairedDevices: true`，从已有验签历史读取原设备绑定；保留现有日志及撤销记录，不初始化新配对。日常服务持续运行，原两条 WebSocket location 使用 660 秒读取超时；`broker.maxOwnerRoomIssues` 使用 100000；实际 `broker.roomTtlMs` 为 540000（9 分钟），双端允许上限仍为 600000，给绝对到期时间比较留余量。

各端仍校验原密钥，使用新鲜挑战、短期房间及会话票据。长期配对替代的是逐次手工准备连接。2026-11-01 已将原手机从 rc2.29 原位更新到 rc2.30、桌面 Harmony 从 rc2.23 更新到 rc2.30，并启用原中继的日常常驻服务。

## 当前结果

新增两项自动连接检查和一项真实本地加密通路检查通过：覆盖已配对启动、掉线重连、手动停止、连接在途停止，以及已关闭旧窗口后复用配对连接和再次连接。其余既有测试未重跑，未访问原设备身份、真实会话或远程中继。严格源码检查覆盖 196 模块；桌面客户端、后端及声明构建通过，手机官方 API26 编译通过。原机自动连接及真实会话列表已通过，现场结果见下节。

完整候选在 `.build/paired-device-rc230/`，手机为未签名 HAP；[产物记录](../evidence/paired-device-artifacts-rc230.json)、[本地加密通路结果](../evidence/device-integration-1793537460903.json)和[手机构建](../evidence/native-build/2026-11-01T12-57-52-797Z.json)记录实际结果。未签名候选保持原字节；原签名安装结果单独记录如下。

## 原机结果（2026-11-01）

经用户明确允许，原签名 HAP 校验和原位安装成功，UID 20020297 不变；未卸载、未清数据，原密钥、配对、历史及深色 UI 保留。桌面只更新 Harmony 依赖与自动连接设置，107 份插件文件与候选一致，并通过正常退出重开加载。原中继已设为开机启用、异常自动重启，代理读取超时为 660 秒，原配对日志及 head 的字节未变。

原手机正常启动后，未点连接、未交换新路由，实际显示“已连接电脑”和“手机MVP体验”“MVP体验”等真实会话。本轮自动发送消息为零，回复和停止操作由用户自行体验。当前连接和中继持续保留，连接不受旧的 30 分钟测试窗口限制。临时亮屏覆盖已通过电源服务恢复，实际熄屏期限回到 600000 毫秒；普通 `power-shell timeout -r` 返回失败的记录保留。[部署记录](../evidence/paired-device-deployment-rc230.json)与本地 `.build/deploy-rc230-20261101/` 保留签装、配置备份、现场失败、最终列表及中继核对结果。

首次等待桌面及锁屏时，手机曾进入 `connection-cleanup-failed`；通过应用内“断开并退出”可正常退出。一次新冷启动在验签后仍拒绝满 600000 毫秒房间，后续实际房间缩至 540000 毫秒并正常重开后连接成功。具体拒绝字段未捕获，不能认定时钟差是唯一根因；等待或 HTTP 503 后的自动恢复、九分钟房间续接及长期稳定性尚未验证，不能据当前连接宣称这些路径全部通过。
