# rc2.16 安装与离线核对

## 当前状态

桌面 Harmony 插件和原手机均已更新至 `0.0.0-rc2.16`，两端冷启动通过。桌面 device 与 feedback 组件运行，private、pairing、link-test 三个包内组件保持关闭；原有身份隔离组配置保留。桌面面板只执行一次 `status`，返回 `bound`。手机显示已配对、未连接，连接按钮禁用，未显示启动诊断错误。没有准备临时路由、连接、重连、重新配对、提交模型任务或更改中继。

本轮范围来自用户明确授权：升级桌面插件并启用 device，复用原签名材料签署手机候选并原位安装，保留数据，只做冷启动与离线核对。完整结果见[安装汇总](../evidence/rc216-installation-20261029.json)。

## 桌面更新

安装包为[已封存插件](../evidence/rc2-controls-artifacts-0.0.0-rc2.16.json)，SHA256 `44335cb027b3f16ae42a0c2ce225e6c8a544f5bcc587152c76d3f2352fdc70c1`。安装后 108 个归档文件与原包逐字节一致。桌面外壳仍为已安装的 `.2`，没有重装或改动其 ACL。

更新前定向备份位于本机 `D:/Temp/dsh-rc216-profile-backup-20261029`，包含原 Harmony 包、profile 配置、manifest 和锁文件。首次官方 CLI 离线 `add` 因 rich-inline 的既有 `mdast-util-to-markdown@2.2.1` 元数据解析失败而退出，相关文件与备份相同。随后只替换锁文件中 Harmony 的归档地址、完整性摘要、版本及两个新增 Host peer 声明，其他依赖节点保持不变。冻结离线安装因缺少 dshmarket 策略元数据而中止；保留供给链检查的冻结安装补齐元数据后通过，跳过解析，复用并新增一个包，下载包数为零，安装脚本禁用。没有降级依赖或关闭策略检查。

包管理器完成替换后，原生插件管理器刷新显示 rc2.16。启用 device 只追加 `id: harmony-mobile-device, disabled: false`，先前所有配置项不变；原有隔离组继续提供原配对命令。空白首页可展开手机控制面板，点击“配对状态”创建一个仅记录本地状态命令的会话，返回 `bound`，没有模型消息。正常退出未出现任务中断提示；冷启动后再次确认 rc2.16、device 和 feedback 均运行。启动工具最初等待可见窗口超时，后续原进程和原生窗口核对成功，日志目录无本轮新增崩溃报告。见[原生桌面证据](../evidence/rc216-desktop-live-20261029.json)。
