# MVP 验收驱动准入

[验收入口](../operations/mvp-verified-start.mjs)现在统一持有窗口准备、预算创建、正常确认框准备及后续验证。预算不足时不打开连接确认，也不创建双端提交 owner；任何准备失败都会等待收尾。[汇总证据](../evidence/mvp-admission-offline-20261031-final.json)记录 188 项定向检查、严格类型和正确性 lint 检查通过。本轮没有访问已安装双端、原配对、HDC 或中继，没有重打包或重开实机窗口；最近原机核验组合仍为桌面 rc2.23、手机 rc2.25。

## 调用顺序

`runBudgetedMvpVerification` 的调用方先建立独立收尾 owner，再提供两个准备端口；不能在函数外另开连接确认或把启动进程、写入启动标记当作准入成功。两个端口均须有界，并等原调用真正完成才返回。

| 端口或阶段 | 责任 |
| --- | --- |
| `prepareWindow({ signal })` | 先完成桌面接口、手机输入清理等耗时准备，再创建有限路由并完成公开字段交换；按实际剩余授权、路由及中继期限创建并返回预算。不得打开连接确认、连接或发送消息 |
| 初始准入 | 入口检查取消、预算和共用时钟；失败时跳过所有连接准备及消息工作 |
| `prepareConnection({ budget, signal })` | 仅在准入后，通过正常界面打开并准备本次连接确认，不提交。操作耗时计入固定连接阶段 |
| 适配器准备 | 确认框准备完成且预算仍有效，才捕获双端最终动作；并行准备的所有原调用结束后才判断结果 |
| `createConnection(budget)` | 仅在准备均通过及预算再次核对后创建提交 owner，直接使用同一个固定预算，不重算或延长期限 |
| 消息、观察及收尾 | 沿用两条消息和独立至少 180 秒的新采样要求，等待任务、适配器、路由撤销和恢复核验完成 |

`prepareWindow` 在入口的异常处理范围内执行，因此预算构造抛错也会进入收尾。确认框准备结束后和适配器准备结束后都会重新检查连接截止；准备超时、取消或失败不能继续提交。取消不会抛弃尚未结束的原调用，也不会提前报告资源已经释放。

返回值分别记录 `admitted`、验证失败、`cleanupFailure` 和 `cleanupLate`。`admitted: true` 只表示最初预算准入通过，不表示已连接或完成验收。预算未能构造时，收尾收到的 `deadline` 为 `undefined`，由已建立的独立窗口 owner 使用自己的有限截止时间；此时 `cleanupLate: null` 表示无法按该预算判断，不能解释为按时收尾。预算已存在时仍分别检查收尾前后是否超期。

## 离线回归

在本目录运行 `node scripts/check-desktop-submission.mjs`，会执行当前源码的 UI、消息、启动及预算回归并严格检查模块。[最终记录](../evidence/desktop-submission-offline-1793422627737-b9855a76.json)为 176 项单元检查和 12 项启动集成检查通过，无失败、取消或跳过；41 项预算及准入检查已包含在该总数中，不重复计数。

[反例记录](../evidence/mvp-admission-negative-20261031.json)从冻结候选提取旧入口，在隔离副本中保留旧调用参数，得到 25 项通过、3 项预期失败，无取消或跳过；修复后的三个反例全部通过。其余新增检查使用受控时钟和异步屏障，覆盖路由创建前的长准备、路由创建后约 98.5 秒准备导致预算短缺、未完成准备时不得打开确认框、确认耗尽阶段预算、各准备阶段取消、迟到结果、部分确认清理、预算构造失败后的异步收尾，以及收尾失败和超期的独立报告。

成功用例通过真实 UI 适配器、启动协调器及消息流程的合成组合，完成两条消息和受控时钟下的 180 秒采样；没有真实设备或模型调用。固定观察、收尾预留及三项实际到期时间的取最早规则不变，未放宽验收条件。

## 使用范围

这是主机操作驱动的修复，不进入手机 HAP 或桌面插件。共享 SDK、手机主工程生成文件和 rc2.24/rc2.25 封存候选等 14 项保护文件指纹不变。旧包中的流程快照和已关闭窗口的启动标记只作历史证据，下一次须使用当前工作区入口及两个准备端口，不能直接复用旧脚本的外部确认动作。

[rc2.25 原机窗口](mvp-rc225-window-20261031.md)的零消息及预算拒绝结果保持不变。手机暖重连、回复、停止和三分钟连接仍未完成实机验收，本轮不据离线通过重开窗口或改动已安装双端。
