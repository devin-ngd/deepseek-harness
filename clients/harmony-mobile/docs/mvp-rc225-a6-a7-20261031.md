# rc2.25 原机连接与输入阻碍

桌面 rc2.23、手机 rc2.25 保持安装版本、原配对和数据。[a6 证据](../evidence/mvp-rc225-a6-20261031.json)和[a7 证据](../evidence/mvp-rc225-a7-20261031.json)分别对应一次独立批准的最长 30 分钟窗口；每个窗口内部的第二次准备沿用原批准和原截止，没有续期。两个窗口均已关闭、不可复用。两轮均未发出测试消息，手机新回复和生成中停止仍未验收。

| 尝试 | 原机结果 | 消息与停止 |
| --- | --- | --- |
| a6 | 连接、13 个真实会话、打开原“MVP体验”，连续观察 199,740 ms | 用户未输入，窗口收尾前未发送 |
| a6b | 正常双端提交后手机未进入连接，流程在消息动作前拒绝 | 三项动作均未提交 |
| a7 | 正常提交并连接，长历史中找不到可见输入区，报 `scroll-budget` | 三项动作均未提交 |
| a7b | 连续连接观察 211,886 ms，60 个样本，最大间隔 4,679 ms；单次原生输入后草稿仍为空，最终报 `ui-port-failed` | 发送和停止均无签发记录 |

a7 中输入框坐标为 `[54,160560][1266,160695]`，可见滚动区域为 `[0,131][1320,2754]`。输入框和任务按钮随整段历史滚动，长历史使主要操作离开可见区域；该布局问题有直接证据。a7b 改用官方原生快速滑动后进入输入阶段，但草稿长度始终为零；不能据此认定输入失败的唯一原因，也不能把驱动到期归为产品连接失败。单次主机调用内的双端提交及桌面提交后核验已在原应用执行。

两轮共四份临时路由均已撤销；每次结束都有独立的中继配置、代理字节、服务 inactive／disabled／MainPID 0 核对。a7b 最终路由历史为 73 条。桌面停止、手机已配对且断开、连接禁用均已独立核验；a7 辅助进程为零，手机亮屏 supervisor 保留。手机曾通过正常“断开并退出”及正常启动更换进程，UID 不变，没有强停、重装或清数据。

[rc2.24 的历史实测](mvp-rc224-window-20261031.md)已验证手机发送、收到助手回复和 183,955 ms 连接；这不等于 rc2.25 已完成两条消息验收，也不覆盖生成中停止。当前下一步是[固定会话输入区的 rc2.26 候选](composer-footer-rc2.26.md)，先完成离线检查；签署、安装和新窗口需要另行授权。
