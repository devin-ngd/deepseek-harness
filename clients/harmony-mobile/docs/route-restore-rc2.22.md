# rc2.22 路由恢复与连接按钮

rc2.22 在核验原配对及有效路由历史后向页面发布就绪状态，保留恢复前台后的主机许可确认。完整候选保持封存；原签名原位安装及该版复验已完成，见[实测与独立收尾](../evidence/mvp-rc222-window-20261031.json)。后续安装组合及未完成项以[rc2.23 原机复验](mvp-rc223-window-20261031.md)为准，不能将离线检查称为 MVP 消息验收。

## 复现与修复

实际原生 owner 恢复运行时，核心原先在读取路由历史前就发布已配对视图，页面随即读取到路由未就绪；路由核验完成后没有再次发布。离线反例使用真实 owner、生成核心和实际 ETS 页面方法：内部连接已可用，但页面最后一次收到通知时仍不可用。[修复前反例](../evidence/route-restore-1793378137853.json)为 2 通过、1 失败；修复后最后一次通知与路由就绪一致，重新确认主机后实际连接按钮条件成立。

[核心实现](../src/native-device-product.ts)将启动发布放在路由历史核验完成之后，并在异步核验后再次检查 owner 是否已关闭。首次配对继续发布正常视图。已撤销路由保持禁用，损坏历史保持阻断，记录字节保留；没有改变路由期限、配对、授权、加密或自动重连策略。这处缺陷能够产生上轮按钮禁用现象，但上轮没有完整生命周期事件，不能认定它是唯一实机原因。[上轮实测和收尾](proxy-burst-mvp-20261030.md)保持原结论。

## 验证与候选

从本目录执行 `pnpm run test:route-restore`，先按当前源码生成原生核心，再运行原生 SDK 替身与 ETS 页面回归。检查器核对生成核心、构建清单和全部输入摘要；源码变化而未重建时明确拒绝，不能以旧生成物验证新源码。[最终 17 项检查](../evidence/route-restore-1793378704242.json)通过，包含三项路由恢复及十四项启动诊断；148 个检查输入前后摘要一致。

总回归入口 `scripts/regression.mjs` 已调用同一核心生成和路由检查命令，本轮未执行总回归或整个仓库测试。[单项合成加密链路](../evidence/device-integration-1793379261529.json)另行验证本机控制证明、动态会话选择和规范快照，通过所选一项用例，其余 22 项按过滤条件未执行。首次检查失败后，最小探针确认沙箱监听可用、回环连接被 EACCES 拒绝；原命令在宿主通过，没有连接原手机或真实中继。

[42 项取消与连接诊断](../evidence/phone-diagnostics-1793378440470.json)、[143 项桌面和消息流程](../evidence/desktop-submission-offline-1793378591826-d9a57789.json)、[11 项期限检查](../evidence/connection-lifetime-1793378596849.json)通过，[定向严格类型检查](../evidence/connection-recovery-typecheck-1793378471209.json)零诊断。各组存在覆盖交集，不合并成互不重复的用例总数。这些离线结果不能证明真实手机已收到回复或停止生成。

[官方 API26 完整构建](../evidence/native-build/2026-10-30T16-42-35-306Z.json)退出 0，输入未变化，保留能力及异常处理警告。沙箱首次因链接已安装 Hvigor 的 EPERM 失败，同一命令在宿主权限下通过；没有签名配置。完整手机 HAP 为 5,618,462 字节，SHA-256 为 `2f9b63728099d2ae82ac8760a8617b88added8f6247133bd92c68e224bc48a1f`。

完整候选复用字节相同的桌面 rc2.19、中继及公开工具 rc2.21，保留代理 burst=3 和 660 秒读取期限提案。[封存清单](../evidence/mvp-candidate-rc2.22-20261031.json)核对 147 项 bundle 输入、73 项原生输入及当前共享 SDK；SDK 摘要与 rc2.21 一致。候选 ZIP SHA-256 为 `321c06aa565c92bce0db893774e20c6b8fc163314e8304e680cb6df012ae3a2e`。[独立产物核验](../evidence/mvp-rc222-artifact-smoke-20261031.json)通过外层清单、HAP/ZIP CRC、载荷版本、复用组件逐字节比较及解包中继的禁用启动。首次封存因 SDK 路径定位错误失败，未完成目录保留为 `.partial-1`，最终候选在新目录重新核验。

## 实机结果与剩余验收

rc2.22 使用原材料签署并原位安装，保留原 UID 和配对。加密连接日志记录约四分三十七秒，主动收尾前没有更早的关闭事件；该轮没有连续三分钟的周期采样。输入框原值为空，但会话只读，消息 0；临时路由已撤销，中继和代理原字节恢复。额外探针曾使用错误的连接状态字面量，后续只读观察使用实际资源标签；该探针不能作为断连证据。

最新安装和实测以[后继原机记录](mvp-rc223-window-20261031.md)为准。原手机已重新连接；亮屏监督仅对原目标续期，MVP 完成或用户取消后恢复原超时，不自动解锁或改变 USB 信任。手机回复与生成中的停止仍未完成，已关闭窗口的批准不可复用。
