# rc2.25 手动体验 a5

本轮 MVP 未完成，未发送两条测试消息，手机回复、生成中停止和三分钟连接均未验收。桌面 rc2.23、手机 rc2.25 沿用，没有重装、重新打包或清除数据。完整结果见[本轮证据](../evidence/mvp-manual-a5-20261031.json)。

## 连接结果

本轮只有一次最长三十分钟授权，两份实际路由及第三份未启动的本地准备沿用同一个原截止，没有延长授权或重新计时；批准现已关闭。两条消息仍未使用。

第一份准备将桌面最终提交也交给用户，分工造成误解。用户随后提交，实时面板独立核验为 `transport-started`；手机没有进入已连接状态，三十次只读样本均为未连接，没有进入真实会话。本次不能据此确定手机握手失败的产品根因。

第二份准备拟由主机同步点击双端，原手机按钮预审完成，但最终提交前达到连接阶段截止；保护检查拒绝继续。桌面和手机最终点击均未发出，正常选择 Deny 并提交，随后停止桌面本地连接。合并提交模块仍没有取得本轮真机执行证据。第三份只生成本地操作文件，没有启动网络 owner、生成路由或连接。

手动消息与只读连接观察可以并行；本轮原型按连接 60 秒、消息 120 秒、观察 200 秒、收尾 45 秒预留，共 305 秒，观察从首个真实已连接样本开始。该原型仍将连接准入放在正常确认准备之前，且手机预审与最终提交之间存在工具往返，实际暴露了准备时序问题；这些本地操作文件未纳入产品或封存候选，也没有新增离线通过计数。

## 手机可见性与收尾限制

第一份自动手机收尾因原应用窗口不可见而失败。正常打开原 EntryAbility 后进程未变；关闭本地窗口后，一个探针误将禁用的连接按钮当作启用控件查询而报错，失败保留。随后独立只读检查确认已配对、未连接、连接禁用，PID `4292`、窗口 `669` 保留。

第二份收尾及正常打开后的多次界面读取仍无法确认原应用窗口。用户报告手机出现系统提示、暂时不能进入 DSH；提示原文尚未取得，不能认定为锁屏、权限问题或应用故障。没有点击系统提示，没有强制结束手机进程；当前手机本地停止状态未能最终核验，不能沿用第一份检查冒充当前结果。手机亮屏监督继续保留。

## 已独立恢复

两份路由均为 epoch 2、revoked、active false。中继为 inactive、disabled、MainPID 0，无临时 dropin；代理和中继配置恢复原始 SHA-256，历史记录从 61 增至 65，旧记录保留。桌面原会话实时面板为 `stopped`。网络恢复成功不代表手机本地停止或 MVP 验收成功。

原配对未修改，没有清除数据、重装或重打包。二十一项既有源码及保护文件哈希核对不变；既有 211 项离线结果未在本轮重跑。下一步先取得手机系统提示原文并恢复原应用可见性，再将所有主机准备放在有限期路由之前，最终准入、手机预审和双端提交放在同一次执行中验证。
