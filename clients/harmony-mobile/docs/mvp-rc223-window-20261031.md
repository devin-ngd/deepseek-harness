# rc2.23 原机复验

当前安装组合为桌面 Harmony 插件 rc2.23、手机 rc2.23，桌面外壳未更换。手机使用原签名材料原位安装，原 UID `20020297` 和配对保留；桌面正常退出后仅更新 Harmony 依赖及对应 lockfile，108 个安装文件匹配候选，其他 profile 配置原字节保留。见[手机签署核验](../evidence/rc223-signing-20261031.json)和[本轮实测汇总](../evidence/mvp-rc223-window-20261031.json)。

本轮仅建立一个有限路由，双端提交间隔约 0.134 毫秒。手机完成加密验证，连续连接观察 182,652 毫秒通过；会话选择和最初读取完成，但输入框在长历史之后，六次安全滚动仍无法触达，消息流程返回 `scroll-budget`。原生输入框原值为空，`send1`、`send2`、`stop` 均为 `not-issued`，实际模型消息 0。手机回复与生成中的停止未验收，MVP 未完成。

后续只读观察中，输入框位于屏幕坐标 y=61,991，页面出现只读及操作失败提示。未取得这次只读提示的具体错误码，不能认定唯一实机原因。离线读取同一目标会话后，语义视图包含四条非用户上下文消息、共 37,957 个文本单位；原生页面将这些内容也作为助手消息显示。原会话记录未复制或修改，仅保存数量和摘要。

双端停止、手机仍已配对未连接、本轮路由 epoch 2 / revoked / active false、中继 inactive / disabled / MainPID 0、无临时 dropin、代理和中继配置原字节恢复均已独立回读；三个驱动和五个日志 reader 已退出。原配对及历史保留，本轮授权窗口已关闭。

rc2.23 修复了会话工具参数嵌套被富内容深度限制拒绝的问题；此前 [rc2.22 实测](../evidence/mvp-rc222-window-20261031.json)及 [路由恢复修复](route-restore-rc2.22.md)分别保留其范围。后续离线修复见[手机会话可用性候选](session-usability-rc2.24.md)，不能将候选检查替代手机消息验收。
