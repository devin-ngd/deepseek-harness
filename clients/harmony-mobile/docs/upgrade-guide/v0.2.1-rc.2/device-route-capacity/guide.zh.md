# Harmony 手机路由历史容量

## 变更

私有手机候选 rc2.20 将 `publicTrustMaxBytes` 和 `core.trustMaxBytes` 从 32768 提高到 524288 字节，与现有设备路由日志上限一致。持久化消息、密钥、绑定标识和路由校验不变。保留的历史超过 32768 字节后，旧手机包无法恢复，安装此类旧包不是受支持的回退方式。

## 迁移

1. 审阅[候选及当前实机结果](../../../route-history-rc2.20.md)。保留原绑定、身份和完整路由历史，不清除数据或裁剪历史以适配旧包。
2. 使用包含两项容量设置的完整 rc2.20 手机 HAP。仅在取得部署批准后用原批准材料签名并原位安装，不卸载应用。
3. 核对安装版本和未变的 UID，再冷启动并验证原已配对状态。追加路由必须保留此前全部 offer、route 和 retired 标识，超限写入必须保持原持久化字节不变。
4. 保留支持现有历史大小的手机包用于恢复。在另行批准的有限窗口中验证连接、真实目录、回复及停止；仅路由签名成功不代表 MVP 验收通过。
