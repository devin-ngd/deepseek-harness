# 手机端深色界面与会话控制改版（2026-11-01）

本轮改原生页面、组件、资源及对应的离线测试和操作脚本。连接协议、配对、Owner、桌面插件和中继没有改动。按用户批准，原手机先后原位安装三个假数据预览包和正式包 rc2.28、rc2.29，均使用原签名材料，未卸载、未清数据；没有连接桌面或中继。

## 交互改动

- 深色界面：[调色板](../harmony/entry/src/main/resources/base/element/color.json)以 #0D0F13 为页面底色、#4D6BFE 为强调色；`EntryAbility` 固定深色模式，状态栏、导航栏和窗口背景均为页面底色。
- 固定顶栏：会话列表显示标题、连接状态点和设置图标；会话页显示返回、会话标题和连接状态；设置页显示返回和标题。顶栏不随历史滚动，内容少时从顶栏下方开始排列。
- 一键连接：首页和设置页的按钮直接显示“连接 主机”，点击即为本次主机批准。点击时如果主机已变化或连接已撤回，操作被拒绝且不发起连接。设置页按钮只在可连接时显示主机，否则显示“连接”并禁用。“允许本次使用这个主机”勾选只保留在配对表单。
- 会话列表：每行显示标题、当前会话的任务状态和项目名；项目多于一个时显示筛选标签。
- 会话页：用户消息为右侧气泡；DSH 回复按 [Markdown 子集](../harmony/entry/src/main/ets/components/MarkdownModel.ets)显示标题、列表、引用、粗体、行内代码和带复制按钮的代码块，表格按等宽原文显示，链接、HTML 和图片不解释。生成中显示加载指示。页面跟随最新输出；只有手指拖动离开底部才停止跟随，同时收起键盘并显示“回到最新”按钮；滚回底部或点按钮恢复跟随。
- 底栏：多行输入框（44–140 vp）和圆形发送按钮。空白草稿不能发送，此时发送按钮变灰；只读或未连接时占位文字说明原因。任务进行中显示状态和“停止生成”，结果未知时显示“核对结果”。
- 错误提示：横幅位于固定顶栏标题下方，不随历史滚动，停在会话底部或键盘弹起时也能看到；按错误代码显示具体说明和代码，可以关闭；关闭后同一错误不再显示，错误变化或清除后恢复。
- 设置页：连接状态、主机、连接和关闭连接窗口按钮常驻；配对设置和诊断默认折叠。主要、次要和危险按钮的最小高度均为 44 vp。

## 操作脚本同步

[手机 UI 适配器](../operations/connection-ui-adapters.mjs)准备连接时不再查找勾选框，而是要求 `product-connect` 按钮文字正好等于用 `labels.connectHost`（含一个 `%s`）填入审核主机后的文字。[消息流程](../operations/mvp-message-flow.mjs)把输入框类型改为 `TextArea`，并要求会话行按钮的边界内有与审核标题一致的文本。调用方传入的回复角色标签改为 `role_assistant` 的当前值“DSH”。

本机模拟器的系统镜像文件已不存在，改用原手机（CMM-AL10，API26）。完整记录见[真机证据](../evidence/ui-redesign-device-20261101.json)，截图在 [ui-redesign-device-20261101](../evidence/ui-redesign-device-20261101/)。

- 安装前：rc2.27、versionCode 2、UID 20020297，已配对、未连接，输入框无草稿。
- 预览包 a1 发现六个问题：会话少时列表在页面中垂直居中；生成中页面不跟随（程序滚动的中间位置被当作用户上滑）；拖动历史时键盘不收起；手势条区域显示浅色窗口背景；空草稿时发送按钮看起来仍可用；次要和危险按钮只有 40 vp 高。均已修复并补测试。
