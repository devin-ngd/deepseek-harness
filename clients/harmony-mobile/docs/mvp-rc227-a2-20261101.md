# rc2.27 原机 MVP 验收

桌面 rc2.23 与手机 rc2.27 已在原手机完成本轮 MVP：从真实会话列表进入“手机MVP体验”，手机发送 `Hello` 后收到新助手回复，再发送长故事请求，在运行态点击停止并收到“已取消”，连续连接观察达到 181.8 秒。[汇总证据](../evidence/mvp-rc227-a2-20261101.json)包含动作记账、原生界面采样、固定诊断和独立收尾结果。本轮未重装，原 UID、配对、数据和其他会话内容保留。

## 原机结果

| 项目 | 实际结果 |
|---|---|
| 原机与应用归属 | 原手机 rc2.27、UID `20020297`，全程同一进程及原生窗口；每次检查完整与可见布局的应用、页面和窗口归属 |
| 双端连接 | 正常桌面确认及手机连接在同一主机调用中提交；双端调用分发记录相差 20 毫秒，桌面提交后面板核验通过，手机完成控制及数据通道握手 |
| 真实会话 | 从原生目录选择既有“手机MVP体验”，核对精确 Session 标识；未创建第二个会话，也未发送桌面 `Ready` |
| 手机回复 | 仅发送一次 `Hello`，确认新助手正文及任务完成，随后才发第二条 |
| 手机停止 | 仅发送一次 `Please_write_a_long_story.No_tools.`，确认运行态后点击一次停止，依次观察到等待电脑确认和已取消 |
| 连续连接 | 50 次原生观察均为已连接，单调时钟覆盖 `181816.0733` 毫秒，最大采样间隔约 6.29 秒，低于 15 秒要求 |
| 实际动作预算 | 两次发送、一次停止；无第三条、无重发、无重连 |

连接观察从 UTC 01:46:33.004 到 01:49:34.822。验收期间未记录到固定读流失败或 socket 失败；主动停止中继后，手机记录两条 socket `code=200/http=0`，发生在验收结束及停止中继请求之后，单独保留，不归入三分钟观察。

回复确认与取消确认仍有明显等待：从发送前新观察到手机回复确认约 52.6 秒，从停止前新观察到手机“已取消”约 18.9 秒。这些时间包含模型、原生界面和采样耗时，不能当作纯传输延迟；后续优先定位体验等待，不能把本次通过扩展为响应速度或长期稳定性通过。

## 收尾与限制

独立核验已确认双端停止、临时路由撤销，中继 inactive／disabled、MainPID 为 0、无临时 drop-in，代理和中继配置原字节一致。原路由历史保留，本轮追加登记及撤销后共 83 条。所有窗口 owner 和诊断子进程退出；测试亮屏保持已结束，手机原屏幕超时恢复。当前手机为已配对、未连接；这次临时连接没有作为常驻服务留下。

窗口内的首次公开字段转存因界面桥不提供 `process` 而失败，发生在手机输入及上传前；改用现有主机验签入口后，在同一个窗口和同一路由继续。验收后的额外截图采集失败，未获得可交付截图；本次成功证据来自真实原生完整／可见布局、正常控件动作及独立结果核验。

这是一个原机、两条消息、有限窗口的 MVP 证据，不代表无人值守或长时间稳定性已验收。此前[约 140 秒断连](mvp-rc226-a2-20261031.md)的唯一根因仍未确认；本次观察没有复现它。[上一轮预算拒绝](mvp-rc227-window-20261101.md)及其零消息结果保持原样。rc2.27 HAP、封存候选和已安装双端未改变；新窗口仍需独立授权，不能复用已撤销路由。
